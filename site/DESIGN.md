# DESIGN — AI 每日简报

方法来源：`codex-ui-designer-kit/SKILL.md`（视觉推导 → 参照 → tokens → 代表页 → 评审表）。本文件只记录有决策价值的内容。

## Brief

- 模式：整体改造（原仓库只有 24 份 markdown，没有页面）
- 使用者：关注 AI 行业的公开读者（PM、工程师、研究者、创业者），每天花 3 分钟知道「今天发生了什么、为什么重要、有什么风险」。作者本人是其中一个读者，私人笔记走 `AI_DAILY_PRIVATE=1` 的完整版
- 核心对象：一期简报（issue）。公开版每期：一句话观点、3 条要闻（一句话 / 为什么重要 / 核心观点 / 这意味着什么 / 风险与待验证 / 原文）、开源项目。完整版另有可落地行动、明日行动、人工验证清单
- 设备：桌面为主（办公），手机转发阅读
- 数据：`outputs/AI-Daily-*.md` 由脚本解析，静态生成，无服务端
- 范围内：首页（最新一期 + 往期）、单期页。范围外：搜索、标签页、订阅、评论

## 风格命题

**给做 AI 产品的人看的每日情报板。** 要传达的是「有人替你盯着前沿，并且已经判断过了」——所以每期必须有一张能单独转发的封面，星级和编号要像仪表读数一样一眼可比。

三个特征：
1. **有封面**：每期封面由数据生成（编号、日期、头条、两条副标题），同一套版式、不同色相，归档页像杂志架。不靠插画填空。
2. **读数感**：期号、星级、日期用展示字体 + 等宽数字；星级永远 5 格显示（亮/暗），跨期可比。
3. **一次性的隆重**：只有首页加载时一段编排动效（封面升起、三条要闻依次出现），其余动效只响应用户动作（hover、展开、翻页）。

舍弃：
- 暖纸色 + 衬线 + 橙色（第一稿，用户否决：像文本拼接）
- GitHub 式白底细线（第二稿，同样否决）
- 深色底 + 单一荧光绿（通用 AI 产物，和「可信情报」气质不符）

## Tokens

颜色（角色 → 值）：
- 夜空底：`--night-1 #0b0f2a` → `--night-2 #181d52`（首页顶部 band、单期页顶部）
- 亮面：`--surface #f4f5fb`（归档/正文区）、`--paper #fff`（卡片）
- 墨：`--ink #10122b`、`--ink-2 #474b6b`、`--ink-3 #8a8ea8`、`--line #e3e5ef`
- 强调：`--violet #6f5cff`（链接、当前、编号）、`--cyan #39d2ff`（封面高光）、`--amber #ffb400`（星级）
- 封面色相 6 组（按期号轮转）：靛 / 青 / 紫 / 珊瑚 / 墨绿 / 石墨

字体（角色 / 家族 / 字重 / 字号 / 行高 / 字距 / 行宽）：
- 展示（logo、期号、封面报头）：得意黑 Smiley Sans（OFL，woff2 1.1MB，`font-display: swap`，回退 PingFang 600）
- 标题：系统 PingFang SC / Noto Sans SC 600，首页 lede 28/1.4，单期 h1 28/1.45，要闻 h2 20/1.4，字距 0
- 正文：同族 400，15/1.75，阅读宽 ≤ 44em（760px 容器）
- 数字：`font-variant-numeric: tabular-nums`（日期、星级、期号）
- 回退验证：字体加载失败时封面报头落到 PingFang 600，版式不变

间距 / 形状：
- 节奏：8 / 16 / 24 / 40 / 64
- 圆角：封面 18，卡片 16，胶囊 999；阴影只用于封面和悬浮（带色相 `rgba(20,24,80,.25)`）

## 动效

| 元素 | 触发 | 从 → 到 | 时长 / 缓动 | 中断 | 减少动态 |
|---|---|---|---|---|---|
| 首页 hero 封面 | 首次加载 | y+24, opacity 0 → 0, 1 | 600ms cubic-bezier(.2,.7,.2,1) | 无（仅 transform/opacity） | 直接显示 |
| hero 三条要闻 | 首次加载，封面后 | y+12, 0 → 0, 1，间隔 80ms | 400ms | 同上 | 直接显示 |
| 封面卡 | hover / focus | translateY 0 → -4, 阴影加深 | 200ms | 离开即回 | 保留阴影变化，去位移 |
| 封面 → 单期页 | 点击卡片 | 同一 `view-transition-name` 共享元素 | 浏览器默认 ~250ms | 不支持时即时跳转 | 浏览器处理 |
| 要闻区块 | 点击首页要闻 | `scroll-margin-top` 定位 + 1 次高亮 | 800ms | — | 无高亮 |

## 响应式

- 桌面 1080 容器：hero 两栏（封面 1.1fr / 文字 1fr）；归档 3–4 列
- 820 以下：hero 单栏，封面在上；归档 2 列
- 520 以下：容器 16px 边距；归档仍 2 列（封面可读）；单期页封面全宽
- 中间宽度检查：860（转折前后）
