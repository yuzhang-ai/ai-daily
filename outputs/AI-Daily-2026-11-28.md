## 今日要闻

### 1. Kimi: 面向科研人员开放 API 积分申请，最高 2 万美元
- 来源链接：[官方介绍](https://www.kimi.ai/news/kimi-for-science-program)；[官方账号帖](https://x.com/Kimi_Moonshot/status/2126154696947871760)
- 类型：行业
- 推荐指数：★★★☆☆
- 一句话总结：月之暗面（Moonshot AI）于 11 月 26 日晚发布 Kimi for Science，面向自然科学、工程及相关交叉学科的科研人员开放申请；入选项目最高可获 2 万美元 Kimi API 积分，第一轮截止 12 月 8 日。
- 关键数字：$20,000 | 入选项目可获的最高 API 积分

**为什么重要：** 实验室向科研人员提供模型能力，常见做法是分配 API 积分或学术席位，而非直接发放现金。OpenAI 的 Researcher Access Program 面向研究负责任部署、风险或社会影响的申请者，官方公开模型的 API 积分上限为 1,000 美元，有效期 12 个月；另有面向理工科学术人员的 ChatGPT 席位计划，但不包含 API 积分。Kimi 此次将申请入口对准自然科学、工程及相关交叉学科，把单笔上限设为 2 万美元 API 积分（约 70 亿 token），同时提供技术支持与新模型优先体验；该额度纯用于模型调用，不设现金资助。

**核心观点：**
1. 官方介绍页的 `datePublished` 为 2026-11-26T13:05:36.017Z，对应北京时间 11 月 26 日 21:05:36。官方账号 @Kimi_Moonshot 于 2026-11-27T03:22:36.000Z（北京时间 11 月 27 日 11:22:36）发帖，写明 Starting today，并给出同一申请页。
2. 入选者最高可获 2 万美元 Kimi API 积分（官方折算约 70 亿 token），具体金额按研究需求和评审结果确定。官方 FAQ 注明，积分仅供模型使用，非现金资助。第一轮申请截止 12 月 8 日，后续将开放更多轮次。
3. 申请面向自然科学、工程及相关交叉学科的研究人员与团队。官方帖文说明对象涵盖博士生、博士后及课题负责人（PI）；积分按研究项目发放，支持与合作者共享。入选项目还可获得 Kimi 团队的技术支持、新模型优先体验以及长期合作机会。联系邮箱为 ai4science@moonshot.ai。

**这意味着什么：** 以 API 积分换取科研工作负载与早期反馈，这条路径并不新：OpenAI 已在 Researcher Access Program 中设立公开模型积分资助，上限为 1,000 美元，按季度评审，且优先面向负责任 AI 与社会影响研究。Kimi 补上的是面向自然科学与工程领域、上限更高的调用额度，以及明确的首轮截止日期。后续值得关注的是评审尺度与实际发放规模，以及该项目能否形成稳定的开放轮次。

**风险与待验证：** 开放申请不等于已获额度，官方 FAQ 注明评选结果与支持细节以最终评审为准。约 70 亿 token 系官方对 2 万美元的换算，本报未按价目表复核。官方介绍页未说明评审周期、入选比例，以及额度是否分阶段发放。
