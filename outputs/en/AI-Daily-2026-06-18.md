# AI Daily 2026-06-18

## One-liner

> The core competitiveness of agents is shifting from "can the model answer" to "can the system run a real workflow to completion, leave evidence and accept human review". The value of an AI PM / FDE is not replacing engineers but organizing business judgment, context, tool permissions, evals and risk control into a reusable workflow.

## Top stories

### 1. Anthropic: Agentic coding and persistent returns to expertise
- Sources: [Anthropic](https://www.anthropic.com/research/claude-code-expertise)
- Type: Research report / Blog
- Rating: 5 stars
- Summary: Anthropic analyzed about 400,000 Claude Code sessions and concludes that the stronger the agent, the more it rewards people who understand the business and can exercise judgment.

**Key points:**
1. Humans mainly decide what to do; the agent mainly decides how to do it.
2. Each instruction from a domain expert triggers more agent actions and has a higher success rate.
3. Success should be measured by verifiable evidence such as passing tests, commits and PRs, not by subjective satisfaction alone.


### 2. arXiv: Agents' Last Exam
- Sources: [Website](https://agents-last-exam.org/); [arXiv](https://arxiv.org/html/2606.05405v1)
- Type: Paper / Benchmark
- Rating: 5 stars
- Summary: ALE evaluates agents with real occupational workflows, GUI/CLI environments and verifiable artifacts rather than static Q&A alone.

**Key points:**
1. Tasks cover 55 sub-industries and 1.5K+ workflows; the goal is economic value, not leaderboard chasing.
2. Evaluation centers on output artifacts: files, tables, CAD, screenshots, code and numerical results.
3. It avoids generic LLM-as-judge where possible, preferring deterministic checks and hard thresholds.

**What it means:** When building customer-operations or WeCom agents, "did the action actually complete" should likewise be grounded in verifiable artifacts: was the tag written, is the message waiting for human confirmation, does the link open, was anyone reached by mistake.

### 3. Cognition: Introducing Devin Desktop
- Sources: [Cognition](https://cognition.ai/blog/introducing-devin-desktop)
- Type: Blog / Product update
- Rating: 4 stars
- Summary: Windsurf evolves into Devin Desktop; the core signal is that the IDE is turning from an editor into an agent command center.

**Key points:**
1. The engineer's workflow is shifting from pair programming to managing multiple local and cloud agents.
2. Spaces let related agents share context, suited to pushing complex tasks forward in parallel.
3. ACP support lets multiple agents plug in, moving the product-level competition to unified scheduling, review and context management.

**What it means:** Future agent products are not just a chat UI but a task queue, a context store, permission control, progress evidence and a human acceptance panel.
