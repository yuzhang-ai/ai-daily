# AI Daily 2026-11-12

## One-liner

> Two roads that others have walked for years both got an official big-vendor version today: Google follows Jev into decision models, AWS follows LocalStack into local cloud emulation. First movers need to recount their moats.

## Top stories

### 1. AWS: AWS Emulator released, an official entry into the lane LocalStack has worked for a decade
- Sources: [Werner Vogels' blog](https://www.allthingsdistributed.com/2026/11/aws-emulator-and-the-engineers-job-when-agents-write-the-code.html); [User guide](https://docs.aws.amazon.com/emulator/latest/userguide/what-is-service.html); [GitHub repository](https://github.com/aws/aws-emulator); [Hacker News discussion](https://news.ycombinator.com/item?id=50456631)
- Type: Open source
- Rating: ★★★★☆
- Summary: AWS released AWS Emulator, a local emulator covering more than 200 services that runs offline without an AWS account, with code dedicated to the public domain under CC0; AWS says all of it was written and tested by agents.
- Key figure: CC0 | public domain; LocalStack's paid tier with comparable coverage starts at $39 per seat per month

**Why it matters:** Emulating AWS locally is not a new need. moto has mocked AWS in Python tests since 2013; LocalStack has offered a full local AWS stack since 2016, has 65k GitHub stars and is the de facto standard, with a free Hobby tier capped at 30-odd services and paid tiers from 55 services up. AWS entered the field itself today: 200+ services, offline, free, CC0. Swami's explanation in Vogels' post is that AWS has too many services to hand-write high-fidelity stand-ins in less than years, so the emulator is generated from 400+ public API models by agents, which then run fidelity tests against real AWS; engineers own the specs, the tests and the merge gates.

**Key points:**
1. 200+ services, generated from 400+ public API models. On Linux it installs as an RPM or Debian package; macOS and Windows use Docker; Rust tests can embed it in-process as a library.
2. The license is CC0-1.0, not Apache or MIT, so there is not even an attribution requirement. The user guide states it is for building and testing only, not production or security testing.
3. The repository was created on September 11, 2026 and published on November 11; it passed 1,900 stars on GitHub and 650 points on Hacker News the same day. Each release publishes per-service fidelity scores, and known gaps live in the `issues/things-that-do-not-work/` directory.

**What it means:** This is another case of a platform owner shipping a free official version over a third-party niche, the same pattern as Chrome's Modern Web Guidance and Google's Decisions API. LocalStack's free tier is now far behind on service count; its paid tiers are left with Snowflake and Azure emulation and team features. The more notable part is how it was built: AWS says publicly that agents wrote and tested the code and humans only guard the gates. It is the first time a major vendor has shipped agent-written infrastructure as a product rather than an experiment. If the fidelity holds up, other clouds have no reason not to follow.

**Risks and open questions:** Fidelity depends on the public API models and the tests against real AWS, and varies by service; check the official per-service scores. "All code written by agents" is AWS's own claim with no outside audit. Of 190 Hacker News comments, 24 compare it with LocalStack, mostly asking whether hard-to-emulate parts such as IAM and event ordering are reliable.

### 2. Google: Gemini Decisions API launches; the decision-model line reaches its third major vendor
- Sources: [Google blog](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/); [Decisions API docs](https://aistudio.google.com/docs/decisions-api); [Simon Willison's test](https://simonwillison.net/2026/Nov/11/gemini-decisions-api/); [Hacker News discussion](https://news.ycombinator.com/item?id=50456791)
- Type: Model release
- Rating: ★★★★☆
- Summary: Google added Gemini Decision 1 to the Gemini API: up to 1,000 closed-set questions per request over text, images, audio, video and PDF, at $0.10 per million input tokens with output not billed.
- Image: ![Gemini Decisions API architecture: one multimodal input plus many questions, scored in a single forward pass with confidence values](images/2026-11-12/2-gemini-decisions-arch.png) (Image: Google)
- Key figure: 3rd | after Jev in September and OpenAI in October, Google is the third major vendor with a decision model

**Why it matters:** The decision-model line has reached a third major vendor in under two months. On September 15 TypeSafe released Jev, the first model that produces no text and only outputs probabilities over given options; on October 6 OpenAI launched the Decisions API in beta on GPT-6 Luna, generally available October 22; on October 25 Parallel added live web retrieval to the same kind of interface; on November 10 Hugging Face added a `decision` pipeline to transformers, and the community settled on "decision model" over "System One". Google entered today with an interface almost identical to Jev's, down to reusing Jev's field name `noul` for yes/no questions.

**Key points:**
1. The model ID is gemini-decision-1. A request shares one input of up to 256K tokens across up to 1,000 questions; the three types are noul (yes/no), choice (2 to 255 options) and score (ordered rubric), each answer carrying a 0–1 confidence.
2. Pricing is $0.10 per million input tokens and $0 for output, the same as OpenAI; Jev is $0.042 and remains the cheapest of the three. On modality, Jev takes text only, OpenAI text and images, Gemini adds audio, video and PDF.
3. Google says it leads a benchmark suite spanning agent routing, reasoning, ranking and multimodal understanding with the lowest calibration error, at nearly 5x lower cost than Gemini 3.5 Flash-Lite via the Interactions API. Integrations are rolling out through OpenRouter, LangChain, Vercel and LiteLLM; Google Cloud support is "coming soon".

**What it means:** Three major vendors converging on one interface shape means pulling routing, policy checks and scoring out of text generation is no longer one company's design choice but a new API layer. For developers the question shifts from "whether to use a decision model" to "whose modality and latency fit my inputs". For a first mover like TypeSafe, differentiation is down to price and an earlier ecosystem, the usual position of a small company once the upstream vendors follow. Watch whether Anthropic and Meta follow, and whether Jev-compatible open tools such as Ollaya and Jeeves can standardize the interface.

**Risks and open questions:** "Leads", "lowest calibration error" and "nearly 5x cheaper" all come from Google's own benchmarks with no independent rerun. The sample code uses v1beta. Simon Willison's one-video spot check found Gemini returns probabilities like 0.92 and 0.08 on yes/no questions where Jev and OpenAI return 1.0 or 0.0, so "confidence" does not mean quite the same thing across the three; compare with care.

### 3. Alibaba: Qwen4 announced, Qwen4-Max preview live on Token Plan the same day
- Sources: [Qwen on X](https://x.com/Alibaba_Qwen/status/2120335993643684315); [Qwen WeChat post](https://mp.weixin.qq.com/s/J_zbVHa2R3mmY5KD4v3-bw); [Token Plan](https://platform.qianwenai.com/pricing/token-plan)
- Type: Model release
- Rating: ★★★★☆
- Summary: Alibaba announced Qwen4, its next-generation model, with a Qwen4-Max preview available on Token Plan the same day and already wired into Qwen Office, Qoder, the Qwen app and Qwen Studio; the full release is "coming soon".
- Key figure: 5 weeks | Qwen3.8 weights were still being updated on November 7; Qwen4 is already in preview

**Why it matters:** This is the generation signal from China's top tier. The Qwen3.8 family (2.4T-A95B, Flash-Next, 27B) shipped five weeks ago and its weights were updated as recently as November 7; Qwen4 is already in preview. The stated direction is knowledge and world understanding, coding, agent capability and professional software operation, which overlaps almost entirely with how Google positioned Gemini 4 Carbon two days earlier (long-horizon agent tasks, complex software engineering). The preview is usable, not just announced: Token Plan subscribers can call it today, and Qoder's anonymous test model Qoduck has been switched to this build.

**Key points:**
1. The X post and the WeChat post both went out around 10:00 Beijing time on November 11. The preview is named Qwen4-Max; the full release date is only "soon".
2. Current channels: Alibaba Token Plan (individual from $3/month, with a limited-time preview discount), Qwen Office, Qoder, the Qwen app and Qwen Studio. No open weights and no standalone API price page yet.
3. The same day Alibaba shipped Qwen Code 1.0 Preview (GitHub release November 11), folding the harness capabilities built in Qoder into the terminal coding agent, a tooling move paired with Qwen4.

**What it means:** Chinese vendors are keeping pace with the US cadence: Google opened Gemini 4 Carbon on November 10, Alibaba previewed Qwen4 on November 11, and Baidu released ERNIE 5.5 Flash's post-trained preview the same day. All three put "long-horizon agent tasks" and "professional software operation" in the first sentence, which says the next generation competes on finishing whole tasks rather than on chat quality. Alibaba leading with a subscription channel and deferring weights reverses the Qwen3-era order of open-source first, commercial second; worth watching whether the full release keeps that order.

**Risks and open questions:** The preview publishes no parameters, context length or benchmarks; the official language is limited to results that "made us sit up" in real-task testing. Capability claims wait for the full release and third-party evals. Token Plan discount terms and quotas are as stated on the site.

   What it solves: emulates 200+ AWS services offline on your own machine, giving tests and coding agents an AWS that costs nothing and touches no production resources.
