## Top stories

### 1. Huawei Cloud: openPangu-2.1-Pro preset service goes live, output priced at 3.2 yuan
- Sources: [Release bulletin](https://support.huaweicloud.com/bulletin-maas/bulletin-maas-0001.html); [Model list](https://support.huaweicloud.com/model-list-maas/model_list_0001.html); [Text-generation pricing](https://support.huaweicloud.com/price-maas/price-maas-0002.html); [Retirement notice](https://support.huaweicloud.com/bulletin-maas/bulletin-maas-0002.html)
- Type: Model release
- Rating: ★★★★☆
- Summary: Huawei Cloud MaaS lists the openPangu-2.1-Pro preset service in Southwest-Guiyang 1, at 0.8 yuan per million input tokens and 3.2 yuan per million output tokens.
- Key figure: 3.2 yuan | per million output tokens; previous Pro was 14.5

**Why it matters:** OpenPangu already had two rows on this price sheet. The 30 June 2026 2.0-Flash build is 0.8 yuan input and 1.6 yuan output. The 30 July 2026 2.0-Pro build is 3.2 yuan input and 14.5 yuan output when a request is under 32K tokens, and output rises to 17.6 yuan at 32K or more. 2.1-Pro is version 20261115. Its output price is not split at 32K and not split by peak hours. Cached input is 0.016 yuan; the same column for 2.0-Pro under 32K is 0.8 yuan. The model list sets max output at 384K and max chain-of-thought at 256K. On the same table, 2.0-Pro is 128K and 64K.

**Key points:**
1. The release bulletin opens only the preset service. Public-pool and dedicated-pool deployment are both marked X, and the only region is Southwest-Guiyang 1. The quick-start uses the model parameter openpangu-2.1-pro. The chat URL is `/v2/chat/completions` on `api.modelarts-maas.com`, with an OpenAI-compatible `/openai/v1`. The default limit is 2,000,000 tokens per minute and 100 requests per minute.
2. The model list gives a 512K context and a 500K max input. Deep thinking can be turned off, and the row lists Function Call, prefix continuation, and prefix cache. 2.0-Pro already has those items on the same table, with the same 512K context and 500K max input. Huawei Cloud says 2.1 is a clear step up on agents, code generation, and throughput, and says it is strong at HarmonyOS app development and Ascend operator generation. The page does not give comparison scores.
3. The retirement notice was updated on 5 November. openPangu-2.0-Pro version 20260730 and 2.0-Flash version 20260630 are both scheduled to leave Southwest-Guiyang 1 at 00:00 Beijing time on 30 November. The Pro row names GLM-5.3 as the replacement. The Flash row names DeepSeek-V4.1-Flash-1017. The notice does not name 2.1-Pro as a replacement.

**What it means:** This is Huawei Cloud putting openPangu on the MaaS preset service: Flash on 30 June, Pro on 30 July, and now 2.1-Pro. What 2.1 adds is a lower Pro price and higher caps on output and chain-of-thought, not a new public weight release. The input price now matches Flash on the same sheet, while output is still above Flash's 1.6 yuan. The 5 November retirement page still sends the old Pro to Zhipu's GLM-5.3. The two pages do not yet agree. What to watch is whether the retirement notice is rewritten, and whether 2.1 gets a weight release the way 2.0 did. Until then it is a metered API in one Guiyang region.

**Risks and open questions:** "Clear step up" and the HarmonyOS and Ascend claims are Huawei Cloud's wording on the model list, with no independent retest. The price page says the console is the price that applies. Cache is automatic on a shared prefix, the hit rate is not guaranteed, and a miss can raise time to first token. Failed generations are not billed. The openpangu organization on Hugging Face has 2.0-Pro and 2.0-Flash and no 2.1-Pro. Parameter counts are not on the Huawei Cloud pages above, so the 2.0-Pro scale does not carry over. The retirement notice predates this launch, and its suggested replacements may not have been updated.
